# Architecture Decision Records

Use ADRs for durable architectural decisions that affect multiple modules, operational safety, data integrity, or future replacement cost.

## Naming

```text
ADR-NNNN-SHORT-TITLE.md
```

## Status values

- Proposed
- Accepted
- Rejected
- Superseded
- Deprecated

## Template

```markdown
# ADR-NNNN — Title

- Date:
- Status:
- Decision owners:

## Context

## Decision

## Alternatives considered

## Consequences

## Safety and failure modes

## Validation

## Related decisions and files
```
