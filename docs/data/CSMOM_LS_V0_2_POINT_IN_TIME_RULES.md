# CSMOM-LS-v0.2 — Point-in-Time Rules

**Version:** 0.1  
**Date:** 2026-08-05  
**Authority:** Approved Phase 01 specification plus Phase 02 reconciliation decisions

## 1. Universal time model

All stored timestamps are timezone-aware UTC. `America/New_York` is used only to resolve exchange sessions and human-readable trading rules.

Every temporal record uses, where applicable:

| Field | Meaning |
|---|---|
| `observed_at` | Period or instant described by the record |
| `effective_at` | Time the economic/legal state became effective |
| `available_at` | Earliest time the strategy is allowed to know the record |
| `ingested_at` | Time the local system stored the record |
| `superseded_at` | Time a later revision replaced it |
| `decision_at` | Historical strategy decision time |

Eligibility condition:

```text
available_at <= decision_at
```

No future record may be used as a fallback.

## 2. Session finality

```text
decision_at = official_exchange_close + 30 minutes
```

The close comes from the versioned exchange calendar, including early closes.

A daily record is usable only when:

```text
available_at <= decision_at
quality_status == VALID
```

When a provider does not expose publication time, the adapter assigns a conservative configured finality time that is no earlier than the strategy decision time and records that derivation.

## 3. Immutable revisions

- Raw snapshots are append-only.
- Provider corrections create new snapshots and dataset versions.
- Frozen universes, features, targets, and backtests retain their original parent hashes.
- Restatement does not overwrite historical knowledge.

Point-in-time selector:

```text
select latest revision
where instrument_id matches
  and observed/effective period matches
  and available_at <= decision_at
order by available_at, revision, source_snapshot_id
```

## 4. As-of adjusted prices

The adjustment factor visible at decision time `τ` includes only corporate actions that were effective and available by `τ`.

Store separately:

- raw OHLCV;
- split factor;
- total-return factor;
- factor anchor;
- factor version;
- source snapshot;
- `available_at`.

Signals use as-of adjusted close. Liquidity uses raw close multiplied by raw share volume. Execution uses unadjusted tradable prices.

## 5. Monthly universe

- Freeze at final prior-month official close plus 30 minutes.
- Use only records available by freeze time.
- Preserve membership and reason codes for the entire month.
- Daily operational invalidations can block or exit an instrument without retroactively changing membership.

Required frozen values include:

- adjusted close;
- market cap;
- ADV60;
- valid-session count;
- exchange/listing/security type;
- sector taxonomy and value;
- data/action quality state.

## 6. Point-in-time market cap

Preferred contract:

```text
market_cap_pit = raw_close × shares_outstanding_pit
```

The latest share count must have `available_at <= universe_freeze_at`. Corporate-action transformations may be applied only through the freeze date.

Provider-direct values require validated historical as-of semantics. Current market cap is prohibited in historical queries.

## 7. Sector history

Every sector record requires:

- `instrument_id`;
- `taxonomy_id` and `taxonomy_version`;
- `sector_code` and label;
- `effective_from` and `effective_to`;
- `available_at`;
- source snapshot and revision.

The taxonomy must be frozen before Phase 03. Missing or overlapping history blocks the instrument.

## 8. Earnings schedules

Each schedule version requires:

- event timestamp or event session;
- timing class: `BMO`, `AMC`, `DURING_SESSION`, or `UNKNOWN`;
- `known_at`/`available_at`;
- revision and cancellation state;
- confidence and source.

Historical selection uses only the latest version known at the decision time. Later schedule changes do not rewrite earlier decisions.

Unknown timing is treated as before-open for exit timing.

## 9. Intraday execution benchmark

Required window:

```text
[10:00:00, 10:30:00) America/New_York
```

Required bar frequency: five minutes or finer.

Each interval requires:

- interval start/end UTC;
- interval VWAP;
- volume;
- quality status;
- availability and ingestion timestamps;
- source revision.

All expected intervals must be present and valid. The window VWAP is volume weighted from interval VWAP values. Missing or zero-volume coverage means no fill.

## 10. Spread observation/model

The final historical spread value must be generated by one frozen method:

1. Observed point-in-time quote method; or
2. A deterministic proxy model preregistered before Phase 03.

Required output fields:

- `spread_bps`;
- `method_id` and version;
- input lineage;
- observed/model classification;
- `available_at`;
- quality status.

No entry is permitted when spread is missing, non-finite, suspect, or above 35 bps.

A daily high-low range must not be labeled an observed spread.

## 11. SPY reference data

SPY is a reference instrument only. It requires the same as-of daily-price and corporate-action controls as the tradable universe.

At decision time, compute:

- one-session adjusted return;
- `VOL20`;
- `SMA200`;
- transition/bull/bear regime classification.

Current or future SPY data may not affect an earlier target.

## 12. Short-side limitations

Historical borrow availability may be unavailable. In that case:

- never assume free borrow;
- apply preregistered borrow-cost and unavailability scenarios;
- include dividends owed by shorts;
- report short results separately;
- label executable conclusions as limited;
- block any future paper/live short when current broker borrow state is unknown.

## 13. Fail-closed null policy

| Missing/invalid input | Required result |
|---|---|
| Stable identity or listing | Block instrument |
| Monthly market cap | Exclude from monthly universe |
| Sector history | Block entry |
| Daily price/action data | Block instrument/session |
| Cross section below 20 | No new target for date |
| Earnings history | No final acceptance backtest for affected interval |
| VWAP window | No fill; expire intent |
| Spread estimate | Block entry |
| SPY stress inputs | No new target for date |
| Borrow status for executable short | Block short |
| Manifest/hash lineage | Invalidate dependent dataset |
